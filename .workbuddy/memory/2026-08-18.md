**踩坑记录（重要）**：
1. jinja2 中 `g.items` 取到 dict 的 `.items()` 方法而非键值 → 须用 `g['items']`
2. `[data-done!="1"]` 不是合法 CSS 属性选择器（`!=` 是 jQuery 扩展）→ querySelectorAll 抛错，须用 `:not([data-done="1"])`
3. CSS 特异性：`html.anim .reveal`(0,2,1) > `.reveal.in`(0,2,0) 会让内容永远隐藏 → 必须写 `html.anim .reveal.in`(0,3,1)
4. 渐进增强：`.reveal` 默认可见，JS 成功才加 `html.anim` 隐藏；IO 之外加了 900ms 初始保险 + 400ms 自终止 interval 兜底，保证任何环境下内容不隐藏
5. `clipboard.writeText` 无权限时 Promise 可能永不落定 → 加 400ms 竞速兜底到 execCommand，保证"点了必有反馈"
6. 头像白底用 `mix-blend-mode: multiply` + `brightness(1.1)` 融入暗色背景（plan 风险节建议的方案）
7. ego-browser 环境：getComputedStyle 返回陈旧值（冻结样式引擎，连 inline opacity:1 都返回 0），但合成器渲染正常 → 用截图像素分析验证渲染（PIL 统计亮/紫像素）；CDP click 偶发超时 → 用 `el.click()` 代替；`captureScreenshot` 用位置参数 `(path, {fullPage:false})`，全页用 CDP `Page.captureScreenshot {captureBeyondViewport:true}` + fs 写 base64
